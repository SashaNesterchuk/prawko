# Реклама + разова покупка назавжди (Польща)

**Канон для бізнесу:** [biznes-kontekst-uk.md](./biznes-kontekst-uk.md). Нижче — продуктова матриця і правила реклами.

**Дата:** 30 липня 2026

**Принцип:** навчання не блокуємо. Free = весь контент + реклама. Plus = без реклами + AI, **один раз назавжди**.

| | |
| --- | --- |
| Формат | Interstitial video; **без банерів** на питаннях |
| Ціна Plus | **24,99 zł** (тест: 19,99 / 29,99) |
| Paywall copy | `Bez reklam + AI-asystent. Jednorazowy zakup na zawsze.` |

---

## Продукт

**Free:** план, практика без ліміту, іспит, помилки / пастки / SRS / збережені / 3-бальні (з рекламою).  
**Plus:** без реклами + AI-чат. Один SKU, без підписки. (v2 опційно: слабкі теми.)

Не робимо: paywall перед іспитом, ліміт 20 питань/день, hard-gate на помилках/пастках, кілька тарифів.

## Вердикт по кожному (маркетинг)

| Фіча | Зараз | Рішення | Чому |
| ---- | ----- | ------- | ---- |
| **Помилки** (`wrong_answers`) | Premium | **Free + ads** | Ядро підготовки. Замок = токсичні відгуки, ріже retention і ad $. |
| **Збережені** | Free | **Free + ads** | Юзер сам зібрав — правильний статус. |
| **Пастки** (`hard_questions`) | Premium | **Free + ads** | Корисний режим, але не «магія»; краще крутить сесії під ads. Hard-gate слабший за помилки, але теж ріже DAU без сильного Plus-pitch. |
| **Розумні повторення** (SRS / `seen_not_mastered`) | Premium | **Free + ads у v1**; кандидат у Plus лише якщо конверсія <2% | Найкращий «розумний» режим для gate серед практики, але щоденний SRS = retention engine для ads і ASA. Спочатку відкрити. |
| **Слабкі теми** (`weak_spots`) | Premium | **Можна Plus (v2)** | Коучинг-фільтр, не must-have для здачі. Найменш токсичний hard-gate. |
| **Складні 3 бали** (`high_points`) | Premium | **Free + ads** | Вага балів на іспиті — практично корисно; собівартість 0. |
| **AI-чат** | Premium | **Plus only** | Єдина чесна hard-цінність + реальна собівартість. |
| **Без реклами** | (мета Plus) | **Plus only** | Основний комфорт-pitch. |
| **Повтор іспиту за рекламу** | soft-gate ads/Premium | **Лишити** | Чесний обмін: хочеш ще симуляцію → interstitial або Plus. Краще за paywall на перший іспит. Перший запуск іспиту — вільний. |
| **Ліміт 20 питань/день** | у config | **Прибрати з продукту** | Суперечить free+ads. |
| **Free AI 8/день** | у config | **Прибрати** | AI тільки Plus, без «спробуй трохи». |
| **Offline у paywall** | заявлене Premium | **Не продавати, поки немає** | Брехня в comparison table = refund/trust risk. |
| **«Іспит з лімітом» у paywall** | copy | **Оновити** | Іспит free; ліміт = реклама на повторі / interstitial після результату. |

### Чому не закривати помилки / пастки / SRS жорстко (коротко)

1. Обіцянка моделі: **навчання відкрите**, платимо комфортом (ads-off) і AI — не фільтрами питань.
2. Ці режими = найдовші сесії → **основний ad inventory**. Gate ріже zł з ads сильніше, ніж додає Plus.
3. Paywall у момент «я накосячив / хочу повторити» = злість, не desire.
4. LTV з ASA тонкий (~2–5 zł) → спочатку **утримати** free-юзера, не відсікати інструменти.

### Коли має сенс повернути gate

Лише після 2–4 тижнів live, якщо Free→Plus **< 2% WAU** і ads eCPM слабкий → тестувати Plus на **слабких темах** (і лише потім SRS). **Помилки не чіпати.**

## Коли показувати рекламу (точно)

Формат завжди один: **повноекранне відео** між екранами. Показ лише якщо юзер **не Plus** і реклама завантажена; інакше — тихий skip.

### 1. Після кожного іспиту — завжди

| | |
| --- | --- |
| Коли | Екран **результату** (повний і міні), одразу після `exam finished` |
| Частота | **Кожен** завершений іспит |
| Cooldown 3 хв | **Не діє** (інакше два іспити підряд = 0 показів) |
| Session cap 6 | Діє |
| Під час таймера / питань іспиту | **Ніколи** |

Головний фіксований момент: іспит закінчився → пауза → реклама → юзер дивиться результат.

### 2. У практиці — кожні 12 відповідей, не частіше ніж раз на 3 хв

Практика = тема, тренер-режими, знаки, будь-яке тренування **поза** іспитом. Відповіді під час іспиту в лічильник **не йдуть**.

Показ, коли **обидві** умови true:

1. з моменту останньої реклами набралось **≥ 12** відповідей у практиці  
2. з моменту останньої реклами минуло **≥ 3 хвилини**

| | |
| --- | --- |
| Де саме | Між питаннями: після feedback / перед наступним (не поверх вибору відповіді) |
| Якщо 12 відповідей за < 3 хв | Чекаємо cooldown; показ на **першій** відповіді після 3 хв |
| Після показу | Лічильник = 0, cooldown стартує знову |

Орієнтир **12** (середина 10–15). A/B: 10 = агресивніше, 15 = м’якше.

### 3. Після короткого тренування (< 12 питань)

Юзер закрив практику з **1–11** відповідями, і з останньої реклами минуло **≥ 3 хв** → **1** interstitial на підсумку.  
Якщо щойно була реклама по §2 — **не** дублюємо.

### 4. Чого не робимо

| Ні | Чому |
| -- | ---- |
| Банер на питанні | Б’є по фокусу |
| Реклама під час іспиту | Ламає симулятор |
| Онбординг / логін / paywall / AI | Інший контекст |
| Resume з фону як окремий тригер | Зайвий шум; вистачає §1–§3 |
| Два покази підряд | Один тригер → один показ |

### Константи

```
practiceAnswersBetweenAds = 12
minMinutesBetweenAds      = 3      // не для «після іспиту»
maxAdsPerSession          = 6
examResultAlwaysAttempt   = true   // ігнорує cooldown; не ігнорує Plus / cap / no-fill
```

### Як це виглядає за вечір

| Сценарій | Покази |
| -------- | ------ |
| 30 питань практики (~15–20 хв) | ~2 (12-та і ~24-та відповідь, пауза ≥3 хв) |
| Здав 1 іспит | +1 на результаті |
| Здав ще 1 іспит одразу | +1 ще раз (cooldown не блокує) |
| Короткі заходи по 5 питань | макс. 1 на підсумку, якщо ≥3 хв |

Нормальна сесія: **2–4** реклами, стеля **6**.
