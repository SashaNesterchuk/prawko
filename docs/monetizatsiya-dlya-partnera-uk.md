# Prawko — модель монетизації

**Статус:** запланована зміна моделі (ще не запущено в продакшн)

---

## Коротко в одному реченні

Користувач **безкоштовно** отримує весь навчальний контент (план, питання, іспит), але бачить **короткі відеореклами**; за **~18 zł одноразово** (Prawko Plus) — **без реклами + AI-асистент** до питань.

---

## Навіщо ми це робимо

Поточна модель (ліміт питань на день, закритий іспит, «преміум-підписка / спринт») погано підходить для нашої аудиторії:

- Люди готуються до **конкретного іспиту**, а не «підписуються на місяці».
- Конкуренти в Польщі часто дають багато контенту безкоштовно або за разову невелику оплату.
- Ми хочемо, щоб додаток **одразу був корисним**, а платіж — це «комфорт + AI», а не «відкрий іспит, інакше нічого».

**Головний принцип:** не блокуємо навчання. Блокуємо лише зручності (реклама) та AI-чат.

## Три канали заробітку

| Канал                                    | Хто платить                       | Що отримує                         |
| ---------------------------------------- | --------------------------------- | ---------------------------------- |
| **1. Реклама (безкоштовні користувачі)** | Рекламодавці через Google AdMob   | Ми отримуємо дохід за покази відео |
| **2. Prawko Plus (разова покупка)**      | Студент у App Store / Google Play | ~18 zł один раз → без реклами + AI |
| **3. Школи (B2B)**                       | Автошкола                         | Коди доступу для учнів (як зараз)  |

Ці три канали **не конкурують**, а доповнюють одне одного:

- Реклама — масовий безкоштовний трафік.
- Plus — ті, хто вже «підсів» і хоче комфорт + AI.
- Школи — стабільний B2B, особливо для іммігрантів (UA / EN).

## Що безкоштовно (з рекламою)

| Функція                                       | Доступ                    |
| --------------------------------------------- | ------------------------- |
| План навчання («Сьогодні»)                    | Повний                    |
| Практика по темах                             | Без ліміту питань на день |
| Швидкі режими (помилки, збережені, невивчені) | Повний                    |
| Симулятор іспиту (повний і міні)              | Повний                    |
| Готові пояснення до питань (без AI)           | Повний                    |
| Закладки, прогрес                             | Як зараз                  |

**Що змінюється порівняно з зараз:** прибираємо обмеження «20 питань на день» і paywall перед іспитом.

---

## Що платне — Prawko Plus (~18 zł, один раз)

| Що входить             | Опис                                                                      |
| ---------------------- | ------------------------------------------------------------------------- |
| **Без реклами**        | Жодних відеореклам у додатку                                              |
| **AI-чат по питаннях** | Можна запитати «чому ця відповідь правильна?», уточнити, задати follow-up |

**Що НЕ входить окремо:** весь навчальний контент і так безкоштовний. Ми не продаємо «доступ до іспиту» — ми продаємо **комфорт і AI**.

### Ціна

- **17,99 zł** у сторах (округлено **~18 zł**)
- **Разова покупка** (non-consumable) — купив один раз, назавжди на цьому акаунті
- **Без щомісячної підписки** як основного продукту

### Чому саме 18 zł

- Низький поріг входу для студента в Польщі
- Психологічно «менше ніж похід у кав'ярню»
- Конкуренти часто беруть 20–50 zł за повний доступ
- Легко пояснити: «один раз заплатив — готуєшся спокійно»

---

## Як працює реклама

### Формат

- Тільки **повноекранне відео** між екранами (interstitial)
- **Без банерів** поверх питань
- **Без реклами під час активного іспиту з таймером** — це важливо для довіри та UX

### Коли показуємо

| Ситуація                                | Частота (орієнтовно) |
| --------------------------------------- | -------------------- |
| Під час практики                        | Кожні ~12 відповідей |
| Після завершення тренування             | 1 раз                |
| Після завершення іспиту                 | 1 раз                |
| Повернення в додаток після паузи 10+ хв | Не частіше 1 разу    |

### Захист від «перегріву»

- Не частіше **1 реклами на 3 хвилини**
- Максимум **~6 реклам за одну навчальну сесію**, потім пауза
- Якщо реклама не завантажилась — користувач **продовжує навчання без помилок**

### Логіка «чим довше сидиш — тим більше реклами»

Це не таймер «кожні 5 хвилин», а прив'язка до **дій**: більше питань → більше показів. Активний студент генерує більше доходу з реклами, але в межах розумного cap, щоб не вигнати людей.

### Хто не бачить рекламу

- Купив **Prawko Plus**
- Активував **шкільний код** (див. нижче)
- (Технічно) під час іспиту з таймером

---

## Шкільні коди (B2B) — без змін концепції

Автошкола купує / отримує коди → учень вводить код у додатку → отримує повний досвід **без реклами + з AI**.

**Рекомендація для продажів школам:**

> «Ваші учні навчаються без реклами та з AI-асистентом — як у платній версії Plus.»

Це сильний аргумент для автошкіл, особливо тих, що працюють з іноземцями.

Школа і прямий Plus **не конфліктують**: різні канали залучення одного й того ж продукту.

## Що ми свідомо НЕ робимо

| Модель                                 | Чому ні                                                  |
| -------------------------------------- | -------------------------------------------------------- |
| Щомісячна підписка як основний продукт | Погана конверсія для «підготуйся до іспиту за 2–4 тижні» |
| Блокувати іспит за paywall             | Занижує retention і word-of-mouth                        |
| Ліміт 20 питань/день                   | Занадто агресивно; краще реклама                         |
| Безкоштовний AI з лімітом              | AI дорогий у собівартості; краще чіткий Plus             |
| Реклама через RevenueCat               | RevenueCat — тільки для покупок, не для ads              |

## Шлях користувача (простими словами)

```
Завантажив додаток
    → Зареєструвався
    → Навчається безкоштовно (план, питання, іспит)
    → Іноді бачить коротке відео
    → Хоче спитати AI «чому?» → бачить пропозицію Plus за 18 zł
    → Купує один раз → без реклами + AI назавжди
```

Альтернативний шлях:

```
Школа дала код → активував → одразу без реклами + AI
```

## З чого складається дохід (орієнтовно)

Цифри грубі, для розуміння порядку величин, не фінансовий прогноз.

### Реклама

- Активний безкоштовний користувач: орієнтовно **1–3 zł / місяць** залежно від активності
- Чим більше MAU без Plus — тим більше ad revenue

### Plus (18 zł)

- Після комісії App Store / Google (~15–30%): **~12–15 zł** з покупки
- Якщо з 1000 активних 3% купують Plus → **~360–450 zł** разово з цієї когорти (не щомісяця)

### Школи

- Фіксована або пакетна ціна за коди / учнів
- Передбачуваніший дохід, ніж масовий B2C

**Висновок для партнера:** на старті реклама може дати більше обсягу, Plus — вищу маржу з мотивованих користувачів, школи — стабільний B2B.

## Юридичне та комплаєнс (коротко)

- Оновити **Політику конфіденційності** (реклама, рекламний ID)
- У ЄС — **згода на персоналізовану рекламу** (Google UMP)
- У сторах вказати, що додаток містить рекламу
- Plus — **разова покупка**, в описі продукту не писати «підписка»

1. **Ціна 18 zł** — фіксуємо чи тестуємо 14,99 / 19,99?
