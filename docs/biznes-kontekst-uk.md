## Що вміє продукт

- План «що робити сьогодні»
- Практика по темах, без денного ліміту питань
- Симулятор іспиту (повний і короткий)
- Знаки, помилки, збережені, пастки, розумні повторення, 3-бальні
- Готові пояснення до питань (без AI)
- **AI-чат по питанню** — лише в Plus

Головний принцип UX: відкрив додаток → зрозумів, що робити зараз → почав. Не дашборд метрик.

## Як заробляємо

**Навчання не продаємо і не блокуємо.** Платять за комфорт і AI.

| Канал | Хто платить | Що отримує користувач |
| ----- | ----------- | --------------------- |
| **Реклама** | рекламодавці (AdMob) | увесь контент + короткі відео між екранами |
| **Plus** | студент у App Store / Google Play | без реклами + AI, **разова покупка назавжди** |
| **Школи (B2B)** | автошкола | коди для учнів = той самий повний Plus |

Підписка **не** є основним продуктом. Кілька тарифів не робимо.

### Free (з рекламою)

План, практика, іспит, помилки / збережені / пастки / SRS / 3-бальні, готові пояснення.

Реклама: **повноекранне відео** між екранами. Без банерів на питаннях. **Ніколи під час іспиту з таймером.** Якщо ролик не завантажився — навчання йде далі. Повтор іспиту: подивитись рекламу або Plus.

### Plus (~**24,99 zł**, один раз)

У сторі показується ціна магазину; у додатку орієнтир **24,99 zł**. Раніше в партнерських чернетках фігурувало ~18 zł — не плутати з поточним каноном.

- Без реклами
- AI-чат («чому ця відповідь?»)
- Без soft-gate на повтор іспиту

Шкільний код = повний Plus (без реклами + AI). Окремий пакет «тільки без реклами» зараз не продаємо.

Paywall: `Bez reklam + AI-asystent. Jednorazowy zakup na zawsze.`

## Свідомо не робимо

- Paywall перед іспитом або ліміт «20 питань / день»
- Щомісячна підписка як головна оферта
- Безкоштовний AI «на спробу»
- Реклама поверх питання або під час таймера іспиту
- Продаж offline / фіч, яких ще немає в додатку
