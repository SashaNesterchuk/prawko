# Анимация первого шага — PL/SK, 10 октября 2026

После онбординга первый круг слегка подпрыгивает: подъём на 5 точек, первый импульс через 0,5 секунды, два прыжка с паузой 0,1 секунды между ними, затем пауза 2 секунды. Движется только первый круг. Системное уменьшение движения отключает анимацию.

Открытие шага без ответа и интерактивный пример онбординга не убирают подсказку. Первый принятый учебный ответ, в том числе неправильный, отключает её. Это относится к тренировке, экзамену и тестам знаков. Маркер сохраняется локально и после перезапуска, смены страны и сброса учебного прогресса. Для существующих пользователей учитываются старые ответы и тесты знаков.

## Проверки

29 тестов Jest для логики шагов, первого ответа и жизненного цикла экзамена прошли. Дополнительно старые сценарии чешского экзамена прошли; в его тестовом окружении остаётся предупреждение неполного mock AsyncStorage.

Maestro PL: подсказка остаётся после открытия/закрытия первого шага без ответа, исчезает после ответов в третьем; ошибка и исправление в первом не возвращают её, перезапуск сохраняет отключение. Первый запуск проверки кольца прервался во время обновления кода; повтор на окончательном коде прошёл.

TypeScript по-прежнему показывает только шесть известных ошибок вне этой правки. Новых ошибок нет. Проверка diff прошла.

Maestro SK: открытие/закрытие без ответа сохраняет подсказку; ответ в третьем шаге отключает её. Отдельный свежий запуск подтверждает показ до обучения. Четыре окончательных запуска/варианта прошли.

[Видео движения](first-step-bounce.mp4) записано на iPhone 17 Pro через agent-device. Анализ 153 кадров: верх первого зелёного круга меняется между 742 и 756 пикселями при масштабе 3×, около 4,7 точки. Это подтверждает фактическое движение, а не только наличие контейнера анимации. [Измерение](motion-check.json).
