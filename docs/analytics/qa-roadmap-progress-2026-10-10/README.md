# Старт и прогресс обучения — PL/SK, 10 октября 2026
> Обновление: отдельный пример онбординга отменён по запросу пользователя. Снова используется категория → дата экзамена → главная. Материалы ниже сохраняют историю предыдущей итерации; анимация и исправления прогресса остаются.

> Этот отчёт описывает предыдущую итерацию. Выбор страны/языка на первом экране отменён; актуальные изменения и проверки — в [отчёте исправлений](../qa-onboarding-correction-2026-10-10/README.md).

## Путь пользователя

1. Открыл приложение → на существующем экране категории увидел страну экзамена, язык обучения и короткие пояснения. Автоматические значения теперь видны. Страну можно изменить здесь же; для Польши — и язык. Для Словакии показана словацкая, единственная поддерживаемая сейчас локализация. Дополнительных страниц нет.
2. Попал на главную → первый шаг слегка подпрыгивает на 3 точки примерно раз в 3 секунды. После первого принятого ответа подсказка прекращается и сохраняет это состояние после перезапуска и смены страны. При уменьшении движения анимация отключена. Дополнительного окна на главной нет.
3. Открыл шаг → получил закреплённый за ним набор вопросов. Правильные ответы постепенно заполняют кольцо вокруг номера; неправильные его не заполняют. Процентов внутри круга нет.
4. Ответил верно на 2 из 3 вопросов → увидел примерно две трети кольца, без галочки. Открыл этот шаг снова → получил один оставшийся вопрос. Исправил ошибку → увидел обычный зелёный круг с галочкой.
5. Позже повторил вопрос и ошибся → уже подтверждённый прогресс не уменьшился: критерий — правильно ответил хотя бы один раз. Исправление того же вопроса в отдельной тренировке тоже учитывается.

## Сохранение и старые данные

Набор вопросов и уникальные правильные ответы сохраняются локально отдельно для каждой страны, категории и шага. Изменение содержания вопросов делает старый набор неподтверждённым. Лимиты бесплатного доступа остаются действующими; открытие последующих доступных шагов не требует 100% предыдущего.

Старые отметки «закончил сессию» не содержат набора вопросов и не доказывают правильные ответы. Для PL/SK они больше не дают учебному шагу галочку. Общая статистика ответов сохраняется; прогресс нового кольца накапливается при прохождении закреплённого набора. Чехия использует прежнюю логику. Официальный симулятор экзамена остаётся отдельным сценарием.

## Проверка

На iPhone 17 Pro, iOS 26.0, прошли 7 сценариев/вариантов Maestro: кольцо/ошибка/исправление/перезапуск отдельно PL и SK; редактирование страны и языка; завершение онбординга; пропуск даты; открытие следующего шага; прежний результат CZ.

63 теста в 10 наборах Jest прошли. Девять новых проверяют закреплённый набор, уникальность правильных ответов, исправление в другой тренировке, изоляцию страны/категории, лимит повторной сессии и полный знаменатель при сокращённом первом занятии, изменение содержания, отсутствие округления до ложных 100% и сохранение CZ.

Проверка TypeScript показывает только шесть ранее известных ошибок в существующих экранах знаков, локальном экзамене, каталоге тем и режимах тренировки. Новых ошибок в изменённых компонентах нет.
