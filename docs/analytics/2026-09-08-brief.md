## Что сделать в первую очередь

1. Починить чешские `question-images` (превью webp). Это единственный повторяющийся клиентский фейл.
2. Разобрать first-start: слишком легко выйти с 0 ответов; после skip люди часто всё равно тренируются в другом режиме — spotlight можно не блокировать Home, но diagnostic надо короче / с автосейвом.
3. Ограничить `high_points` (не 154 вопроса за раз).
4. Проверить клиентский RC hydrate: error 35 не должен оставлять paywall пустым до конца сессии. Пока Plus не продаётся.
5. Не ждать конверсии из экранов, которых в текущем онбординге уже нет (`notifications` / `minutes` / `level` / `school_code` / `access` / `preview`) — каталог и дашборд ещё их считают.
