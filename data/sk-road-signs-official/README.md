# Slovakia official road-sign media

This directory contains the seven official annexes to Slovak regulation
30/2020 Z. z. in the 31 March 2024 time version.  `source/` preserves the
downloaded PDFs; `rendered/` contains page PNGs at 144 dpi for local visual
review only.  Individual signs have deliberately not been remapped to Polish
or Czech identifiers.

The source URLs, checksums, and page counts are in `source-manifest.json`.
No file in this directory has been uploaded to Storage or a database.
